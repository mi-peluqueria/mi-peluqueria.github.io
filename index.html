Conectar dispositivos

Para que el móvil y el ordenador compartan las mismas citas, se necesita configurar esto una sola vez.

  1. Abre console.firebase.google.com con tu cuenta de Google.
  2. Pulsa «Crear proyecto».
  3. Pulsa el icono </> (Web), ponle apodo y «Registrar app».
  4. Copia el bloque const firebaseConfig y pégalo abajo.
  5. En «Realtime Database» → «Crear base de datos» → «Modo de prueba».
  6. Vuelve aquí y pulsa «Conectar».
